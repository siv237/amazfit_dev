# ХМНИЦ (оператор РНИС Хабаровска)

МБУ г. Хабаровска «Хабаровский межотраслевой навигационно-информационный центр» —
оператор региональной навигационно-информационной системы (РНИС) города.

- Сайт: `https://www.nic27.ru/` (проверено 2026-09-12, HTTP 200)
- Адрес: 680021, г. Хабаровск, ул. Ким Ю Чена, 42
- Контакты: +7 (4212) 45-25-05, `hmnic@inbox.ru`

## Что известно

- К РНИС подключён весь транспорт регулярных пассажирских перевозок города.
- На сайте — новости о выходе транспорта на маршруты; **публичной витрины реальных
  данных и API нет**.
- Реализация системы мониторинга отдана на аутсорс публичному порталу
  `smarttransport.online` (см. [smarttransport-online.md](smarttransport-online.md)).

## Зачем это нам

ХМНИЦ — первоисточник данных. Если нужен легальный стабильный доступ, имеет смысл
написать на `hmnic@inbox.ru` с описанием некоммерческого проекта для часов и
запросить доступ/разрешение.
