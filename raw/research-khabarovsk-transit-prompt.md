# Промт для поисковой ИИ: данные о транспорте на остановках Хабаровска

Скопировать целиком в поисковую ИИ-систему с доступом в интернет.

---

Ты — исследовательский ассистент с доступом в интернет. Нужно выяснить, откуда
можно получать **онлайн-данные о прибытии общественного транспорта на остановки в
Хабаровске (Россия)**, чтобы затем встроить это в мини-приложение для часов на
**Zepp OS** (Amazfit GTS 4). Приложение умеет только **HTTPS GET** и разбор **JSON**;
в идеале — без API-ключа или с бесплатным ключом.

Ответь по пунктам, с точными URL, примерами запросов и источниками. Помечай, что
подтверждено, а что предположение. Указывай дату/актуальность данных.

## 1. Первоисточники данных
- Какие официальные источники существуют: администрация Хабаровска, перевозчики
  (МУП/автопредприятия), региональная навигационно-информационная система (РНИС),
  оператор ГЛОНАСС, ситуационный центр/ЦОДД, транспортный портал Хабаровского края.
- Есть ли **публичный API/веб-сервис**, **GTFS** (расписания) или **GTFS-Realtime**
  (положение/прогноз) по Хабаровску.
- Есть ли открытые данные (open data) города/края с маршрутами, остановками и
  расписаниями.

## 2. Откуда берут данные Яндекс.Карты и 2ГИС
- Источник данных по Хабаровску у Яндекса и 2ГИС (собственные трекеры, данные
  перевозчиков, ГЛОНАСС-оператор, интеграторы).
- Есть ли у них API для прогноза прибытия (Яндекс.Расписания / Яндекс.Транспорт API,
  2GIS API): условия, стоимость, лимиты, нужен ли ключ, есть ли бесплатный уровень.
- Можно ли легально получать те же данные **напрямую у первоисточника**.

## 3. Агрегаторы и сервисы
- Какие сервисы/API отдают прогноз прибытия по остановке для Хабаровска
  (например, «Транспорт Хабаровска», «Умный транспорт», bus55, Яндекс.Расписания,
  CityBus, OpenTripPlanner-инстансы и др.). Точные URL и примеры запросов.

## 4. Технические детали для каждого найденного варианта
- Базовый URL, метод, параметры (остановка, маршрут), формат ответа (пример JSON).
- Аутентификация (ключ/токен/нет), HTTPS, CORS, лимиты, требования к User-Agent.
- Как узнать **идентификатор остановки** и список маршрутов (справочники/endpoint'ы).
- Это реальное время или только статическое расписание.
- Ссылки на документацию и живые примеры (с датой проверки).

## 5. Практическая рекомендация
- Ранжируй варианты по критериям: бесплатность, простота (один GET), легальность/ToS,
  надёжность, покрытие Хабаровска.
- Для лучшего варианта — пошаговый пример: запрос по конкретной остановке (ID или
  координаты) → пример ответа → как получить «маршрут и через сколько минут придёт».
- Если прямого открытого API нет — какие **законные** обходные пути (официальный API
  перевозчика, запрос доступа, парсинг публичной веб-страницы) и что для этого нужно.
